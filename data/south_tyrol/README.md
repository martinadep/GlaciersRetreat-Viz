# South Tyrol Glaciers

This part of the project visualizes glacier change in South Tyrol (Alto Adige, Italy) over two decades, based on the homogenized glacier inventories published by Galos, Klug & Dinale (2022).

## What's in this page

The dashboard page (`pages/3_South_Tyrol.py`) tells the story of glacier retreat in South Tyrol through three views:

1. **Interactive map** — toggleable layers showing per-glacier area loss (1997→2017) and glacier extents in 1997, 2005, and 2017. Overlaying the year layers makes spatial retreat directly visible.
2. **Aggregate statistics** — total area, number of glacier parts, and average part size for each inventory year, illustrating fragmentation: less ice, split into more (smaller) pieces.
3. **Regional change** — relative area loss by mountain group, revealing that loss is geographically uneven (eastern groups retreated faster than western ones).

## Data source

The visualizations are based on the **Homogenized Glacier Inventories for South Tyrol 1997–2005–2017** (Galos, Klug & Dinale, 2023), available at:

- Zenodo: https://doi.org/10.5281/zenodo.7615565
- Paper: Galos, S.P., Klug, C. & Dinale, R. (2022). *20 years of glacier change: the homogenized glacier inventories for South Tyrol 1997-2005-2017.* Geogr. Fis. Dinam. Quat. 45, 171–183. https://doi.org/10.4461/GFDQ.2022.45.6

The dataset consists of three ESRI shapefiles (`SGIhom_1997`, `SGIhom_2005`, `SGIhom_2017`) in ETRS89 / UTM Zone 32N (EPSG:25832). Each polygon represents a single glacier part. Key columns: `HOM_ID` (stable glacier identifier across all years), `PATCH_XX` (part identifier per year), `AREA_XX` (km²), `ALT_*` (elevation in m a.s.l.), `REGION` (mountain group), `ASPECT_*` (orientation), `SLOPE_MEAN` (°).

## Reproducing the data pipeline

1. **Download the raw shapefiles** from the Zenodo DOI above and place the three folders (`SGIhom_1997`, `SGIhom_2005`, `SGIhom_2017`) into `data/south_tyrol/raw/`.

2. **Update the path** in `src/preprocess_south_tyrol.py` if needed:
   ```python
   RAW_DIR = Path("data/south_tyrol/raw")
   ```

3. **Run the preprocessing script** from the repo root:
   ```bash
   python src/preprocess_south_tyrol.py
   ```
   This loads all three shapefiles, cleans placeholder values (`-9999`, empty strings), fixes a known region-name typo (`"Ortergruppe"` → `"Ortlergruppe"`), aggregates parts to the glacier level via `HOM_ID`, simplifies geometries to ~20 m tolerance for web rendering, and writes the six output files into `data/south_tyrol/processed/`.

4. **Run the dashboard:**
   ```bash
   streamlit run Home.py
   ```
   Click the *South Tyrol* button.

## Notes on the data

A few quirks discovered during exploration, worth knowing if extending this work:

- **One row = one glacier part, not one glacier.** Some glaciers (especially in 2017) are represented as multiple polygons. Use `HOM_ID` to aggregate parts back to whole glaciers.
- **Fragmentation is a real signal, not a data artifact.** The number of glacier parts rises from 325 (1997) to 549 (2017), but distinct glaciers (`HOM_ID`) decline from 234 to 204 over the same period. Disappearing glaciers and fragmenting survivors happen simultaneously.
- **`-9999` and empty strings** are used as missing-value placeholders, mostly in `CGI_ID`, `WGMS_ID`, names, and some 2005 elevation/slope/aspect fields. The preprocessing script converts these to proper `NaN`.
- **The Sesvenna Group disappeared** between 1997 and 2005. Its single glacier is recorded as -100% in `regional_change.csv` after the preprocessing step explicitly handles regions that no longer exist.
- **`ALT_MEAN` is `(ALT_MIN + ALT_MAX) / 2`** per the metadata and is described as "useless for most applications" — `ALT_MEDIAN` is the meaningful per-glacier elevation summary.
- **1997 inventory has higher uncertainty** than 2005/2017 because no DTM is available for the 1992/97 orthophotos and the 1999 DTM substitute has 20 m resolution. Individual-glacier elevation/volume change in 1997 is unreliable; aggregate scales (mountain group, full study area) are meaningful.
